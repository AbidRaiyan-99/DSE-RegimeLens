# Module 17 — DSE Stock-Movement Regime Classification

Files: `literature_review.md`, `methodology.md`, and `experiment.ipynb`.

Open the notebook in Google Colab, run all cells, upload your DSE CSV when prompted, inspect the metrics and confusion matrices, replace the bracketed findings with actual results, then save the notebook with outputs visible.

The notebook uses the 50 trading codes with the most observations for runtime. The target is the five-observation forward return class (bullish above +2%, bearish below -2%, otherwise neutral). This does not predict the DSE index and is not investment advice.
